# QPL Fantasy — логотип

Знак: голубой объёмный значок, внутри золотой **шаңырақ** (кольцо и по три перекрещённые дуги күлдіреуіша, выгнутые к центру). Цвета повторяют флаг Казахстана.

| Файл | Для чего |
|---|---|
| `qpl-logo.svg`, `qpl-logo-1024.png` | основной знак (значок с «бортиком» снизу), прозрачный фон |
| `qpl-logo-square.svg` | знак во весь квадрат: основа для аватарок и иконок |
| `qpl-telegram-avatar-640.png` | аватарка бота в Telegram (Telegram сам обрезает в круг) |
| `qpl-app-icon-1024.png` | иконка приложения (система сама скругляет углы) |
| `qpl-lockup-light.svg/.png` | знак + «QPL Fantasy» + подпись, для светлого фона |
| `qpl-lockup-dark.svg/.png` | то же для тёмного фона |

Во всех SVG буквы переведены в контуры, поэтому шрифты для отображения не нужны.

## Цвета

| | HEX |
|---|---|
| Голубой (верх значка) | `#3AA7DF` |
| Синий (низ значка) | `#0A74AA` |

| Золото (шаңырақ) | `#FFC83D` |
| «QPL» на светлом / тёмном | `#08608E` / `#8ED0F2` |

## Шрифты в логотипе

- «QPL Fantasy» — Rubik Black (900)
- «ҚАЗАҚСТАН ПРЕМЬЕР-ЛИГАСЫ» — Nunito ExtraBold (800)

## Важно

Подпись «Қазақстан Премьер-Лигасы» описывает, по какой лиге игра. Перед публичным запуском заменить на «Қазақстан Премьер-Лигасы бойынша фэнтези» и добавить пометку «Неофициальная игра, не связана с ПФЛК» (см. спецификацию, раздел 11).

Файлы собираются скриптом из векторного описания; перед регистрацией товарного знака стоит отдать знак дизайнеру на финальную отрисовку.
