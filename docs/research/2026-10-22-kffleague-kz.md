# kffleague.kz как источник данных ҚПЛ: результаты проверки

Дата: 2026-10-22

## Что за сайт

kffleague.kz — текущий официальный сайт Казахстанской Премьер-Лиги (сезон 2026). Прежний сайт qfl.kz остановился на сезоне 2024.

- Сайт на Next.js. Данные встроены прямо в HTML страницы (`self.__next_f`), отдельный запрос к API для них не нужен.
- `robots.txt` разрешает обычные страницы и запрещает `/api/` и `/_next/`. Мы читаем только страницы, API не трогаем.
- На запрос без браузерного User-Agent nginx отвечает 403.
- В `sitemap.xml` около 1046 матчей, 244 игроков, 72 команд.

## Страница матча `/ru/matches/<id>`

| Данные | Есть | Комментарий |
|---|---|---|
| Составы (старт и запас) | ✅ | `player_id`, номер, позиция `GK/DEF/MID/FWD`, капитан, фото, схема |
| Голы | ✅ | минута, автор, команда |
| **Ассисты** | ✅ | `assist_player_id` / `assist_player_name` в событии гола |
| Пенальти | ✅ | отдельный тип `penalty` |
| Карточки | ✅ | `yellow_card`, `second_yellow`, красная |
| Замены | ✅ | минута, кто вошёл и кто вышел |
| Статус и live | ✅ | `is_live`, `live_phase`, счёт |
| PDF-протокол | ✅ | `protocol_url` |
| Минуты игроков | ⚠️ | прямо не даны; считаются из состава, замен и удалений |
| Сейвы вратарей | ❌ | на странице нет; статистика матча (`has_stats`) грузится через закрытый `/api/` |
| Рейтинг игроков | ❌ | нет |

Ассисты проверены на 9 матчах сезона 2026 (id 896, 920, 950, 970, 993, 1000, 1010, 1020, 1030): **13 из 16 голов с игры** имеют ассистента (81%). Это нормальная доля: часть голов действительно забивается без передачи.

## Страница игрока `/ru/player/<id>`

Сезонные суммы по турнирам: матчи, выходы в старте, минуты (`time_on_field_total`), голы, голевые передачи, удары, передачи, перехваты, xG, карточки. Сейвов нет даже у вратаря.

## Вывод

Для очков нам хватает почти всего: составы с позициями, минуты (через расчёт), голы, ассисты, карточки и пенальти. Сухой матч и пропущенные мячи считаются из счёта и минут.

Не хватает сейвов. Варианты:

1. Попросить у лиги официальный доступ к данным (лучший путь и для этапа 2).
2. Вносить сейвы вручную в админке.
3. Убрать очки за сейвы из правил.

Бонус за рейтинг отключаем, рейтинга в данных нет.
